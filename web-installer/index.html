ESP32-S3 · USB setup

Ukraine Status Panel

Waveshare ESP32-S3-Touch-LCD-7B — перше встановлення через USB.

  1. Підключіть панель напряму через USB.
  2. Запустіть інсталятор і дочекайтесь завершення прошивання.
  3. Налаштуйте Wi-Fi через Improv Serial або Setup AP.

Інсталяція стирає попередню конфігурацію цього ESP32-S3.

Браузер: потрібна підтримка Web Serial і пряме USB-підключення.

Налаштування: вікно Setup/Improv активне 15 хвилин; після тайм-ауту перезапустіть живлення панелі.

Публічний образ доступний лише після апаратної перевірки саме цієї версії.
