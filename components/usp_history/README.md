# История событий

Кольцо32 событий сохраняется в прежнем NVS формате v1: событие12 байт,
весь blob404 байта. Ключ, версия и контрольная сумма не менялись.

Для новых событий графика сохраняется полная группа, например3.2.
В поле flags события SCHEDULE записана подгруппа1 или2. Значение0
в старых записях означает «подгруппа не сохранена»: показывается3.?,
а не вымышленная3.1. Старые события сохраняются без очистки и переписывания
при загрузке. Текущая настройка группы не подменяет данные старого события.

Production передаёт group_label() одним owning значением; отдельные
group_number()/subgroup_number() не смешиваются. Запись, фильтрация
повторов и обычное отложенное сохранение остаются общими для всей истории.
Новые flags не изменяют формат ENERGY/THREAT. Старые прошивки смогут
прочитать blob, но их прежний вывод продолжит ошибочно добавлять .1.

Проверка: python tests/history-subgroup-native.py. Подробности — в
tests/history_host/README.md. Данные нативной проверки не являются
проверкой реального NVS или экрана панели.
