# Поля секретов только для записи

Компонент сохраняет привычное текстовое поле пароля и действие set_action.
Публичное состояние всегда пустое: Native API и Web не получают введённое
или восстановленное значение. Для внутренней логики доступен secret_value().
clear_value() очищает внутреннее значение и публичное состояние.

Компонент предназначен для двух полей проекта: min_length 0, max_length 64,
mode password. У ключа SvitloBot restore_value true. Его имя, ограничения,
ключ preferences и формат length+64bytes совпадают со старым TemplateText.
Пароль временного профиля Wi-Fi имеет restore_value false: только явное
применение сохраняет новые credentials штатным механизмом Wi-Fi.

Компонент не выводит секрет в журнал и не публикует его при загрузке.
Проверка tests/secret-text-native.py использует actual старый saver/setup
из установленного ESPHome, synthetic storage и callbacks. Это проверка
совместимости кода и формата, а не тест смены credentials рабочей панели.
