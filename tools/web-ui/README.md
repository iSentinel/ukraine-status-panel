# Инструменты сборки Web UI

Нужны Node.js 20+ и npm. В корне проекта выполнить:

    npm ci --prefix tools/web-ui
    python3 scripts/build-web-ui.py
    python3 scripts/build-web-ui.py --check

Версии зависимостей и их integrity закреплены в package-lock.json.
Сборка использует локально установленные зависимости и не обращается к сети.
Terser уменьшает имена локальных переменных, не меняя имена свойств DOM/API.
Он не попадает в прошивку. Бюджет встроенного JavaScript — 16384 байт после gzip: это фактический размер PROGMEM-ресурса ESPHome. Raw/minified размер отдельно не ограничивается.
NODE_BIN позволяет указать путь Node; серверный запасной путь — ../.qa-tools/node/bin/node.
Команды --help показывают справку Python-сборщика.

Свойства с внутренним префиксом __usp сокращаются только внутри приложения; свойства DOM и протокола API не переименовываются. Playwright используется только для проверки браузера.
