# Проверка эффекта листания

Обычные кнопки и свайпы пока переключают страницы мгновенно.
Проверка не сохраняет новый режим и не меняет сеть или правила обновления.
Она доступна через существующий защищённый Native API.

Действие `usp_qa_transition_probe` принимает:
- `page`: 3 (питание) или 4 (история);
- `animated`: false для контрольного мгновенного перехода, true для сдвига;
- `reverse`: направление сдвига, false влево, true вправо.

Сдвиг запрашивается на 350 мс. Наблюдатели автоматически удаляются через
2000 мс. Повторный запрос во время проверки, тот же экран и другие номера
отклоняются. На Home эта проверка не действует: там используется отдельный
быстрый путь с готовым кадром, который нельзя показывать перед сдвигом.

Перед запуском сохранить текущую страницу, режим и регион в новом журнале.
Начать UART460800, проверить версию. Не запускать параллельные проверки
навигации. Выполнить контрольный и анимированный переходы в обе стороны.
После каждого запросить свежее состояние страницы и сохранить
`TRANSITION_PROFILE`. После проверки вернуть исходную страницу, независимо
проверить исходные режим и регион. Не повторять неопределённые команды.

Поля результата:
- frames: число завершённых циклов рисования до первого кадра после SCREEN_LOADED;
- first_ms/end_ms: время первого/последнего цикла от запроса;
- loaded_ms: событие завершения смены экрана;
- render_max_ms/gap_max_ms: наибольшее время рисования и интервал готовности;
- heap_min/psram_min: наименьшая наблюдавшаяся свободная память;
- loaded/complete: событие загрузки и последующее завершение рисования.

Это не измерение физической развёртки LCD. Память проверяется в точках событий,
а не непрерывно. UART отдельно проверяется на timeout, panic и перезагрузку.
Оценка плавности глазами остаётся отдельной проверкой.

Для 350 мс заранее используем критерий: не менее 8 циклов, gap_max <=80 мс,
complete=1, отсутствие timeout/фатальных ошибок. Это минимальный критерий
эксперимента, а не обещание 60 FPS. При непрохождении не включать настройку
эффекта для обычной навигации, сначала искать стоимость перерисовки.

Локальные проверки:
```sh
/root/config/.qa-venv/bin/python3 tests/screen-transition-static.py
/root/config/.qa-venv/bin/python3 tests/lcd-navigation-lvgl-native.py --help
```
Вторая проверка собирает реальный LVGL9.5 и проверяет мгновенный переход,
сдвиг, очистку наблюдателей, запрет перекрытия запросов и переход часов через
предел uint32 под AddressSanitizer/UndefinedBehaviorSanitizer.
При недостатке места каталог сборки можно указать в /tmp; не удалять исходники,
frozen images или журналы предыдущих выпусков.
