# Проверка подписей основного экрана погоды

Запуск: python3 tests/weather-page-text-native.py; справка: --help.
--build-dir сохраняет результат в новом каталоге artifacts.

Пять действующих лямбд извлекаются из refresh_weather_ui в YAML.
Тест сравнивает их с прежними: callback1280, named1280, invalid512.
Шесть отрицательных вариантов сначала должны скомпилироваться.
Проверяется также подмена языка снимка общим ui_language.
Язык, видимый текст, порядок действий и границы состояний сохраняются.
Физическая панель, источники данных и авторизация не используются.
