# Общий стиль погодных карточек

Двенадцать карточек обычного и полного экранов используют один YAML-стиль.
Их координаты, размеры, дочерние надписи и действия кнопок остаются отдельными.
Изменение общего стиля действует сразу на все двенадцать карточек.

Проверка weather-card-style-static.py читает три профиля без доступа к секретам.
Она сравнивает полные поддеревья карточек с принятой .376.
Для проверки чувствительности добавьте --negative-controls.
Изменение эталона допустимо только после отдельной проверки нового дизайна.
Сравнение YAML и генерации C++ не является визуальной приёмкой на устройстве.
