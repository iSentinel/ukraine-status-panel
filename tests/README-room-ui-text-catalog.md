# Подготовка каталога экрана «Комната»

Проверены 16 ключей и 48 неизменённых строк для украинского, русского и
английского языков. Прототип сохраняет прежний резервный английский язык
функции pick; существующие обработчики сначала ограничивают язык значениями
0–2 и для неизвестного сохранённого значения выбирают украинский.

В report.json сохранены 4096 сравнений именованных ключей, 512 проверок
недопустимых ключей и четыре отрицательных проверки: неправильная подпись,
резервный язык, значения имён ключей и выход за границу таблицы.
consumer-guard-proof.json проверяет отрицательные варианты привязки,
состояния датчика и вызова отрисовки графика. Всё выполнено на копиях.

Динамическое количество измерений и пропусков, отрисовка графика, данные
Open-Meteo и SHT, цвета и управление памятью остаются отдельной логикой.
Полное обратное восстановление канонического YAML необходимо при внедрении.
До аппаратной приёмки .365 эти файлы в production не устанавливать.
