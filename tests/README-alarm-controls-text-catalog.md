# Проверка подписей будильника

Запуск: /root/config/.qa-venv/bin/python3 tests/alarm-controls-text-catalog-native.py.
Параметр --build-dir сохраняет исходник проверки и журналы в новом каталоге.

Проверка сравнивает 12 подписей каталога с независимыми значениями для всех
256 значений языка: 3072 сравнения. Дополнительно проверяет первый недопустимый
ключ и значение 255: всего 512 проверок. Выполняется с AddressSanitizer и UBSan.
Условия в YAML проверяются отдельно: девять привязок подписей и три привязки
состояния; сохраняются вызовы обновления дней и состояния веб-интерфейса.

Эта проверка не включает реальное срабатывание, звук, касания или аппаратную
приёмку. Отчёт об обратном восстановлении исходного YAML хранится рядом
с артефактами версии. Он подтверждает сохранение остальных действий.
