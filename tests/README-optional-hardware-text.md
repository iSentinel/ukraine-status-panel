# Проверка подписей необязательного датчика

Запуск: python3 tests/optional-hardware-text-native.py.
--help описывает --build-dir для сохранения результатов.

Тест требует две реальные привязки в refresh_optional_hardware_ui,
прежние проверки обнаружения, числовой формат и цвета. C++ с ASan/UBSan
проверяет шесть точных значений UA/RU/EN, два английских резервных значения
и пустую строку для неизвестного ключа. Изолированные четыре отрицательные
проверки сохранены в artifacts/d-i18n-01-optional-hardware-status-preflight-20261027.
Обратное сравнение полного YAML хранится в выпуске .371.

Это автономная проверка текста и структуры кода. Она не доказывает
работу физического SHT4x, не меняет датчик и не подключается к панели.
