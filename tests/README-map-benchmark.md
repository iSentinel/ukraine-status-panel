# Измерение карты
Только для физического устройства. Команда выполняет явные перезагрузки:
    ../.qa-venv/bin/python3 tests/map-refresh-benchmark.py --output artifacts/NEW-DIRECTORY --expected-version 0.115.201-dev --cold-reboots 10
--help выводит справку. Перед каждым restart сохраняется намерение.
После обрыва читать benchmark-progress.json и подтверждать результат по uptime/UART.
Повторное использование каталога запрещено. Статистика описывает максимумы
медленных handler в окне API-логов, не полное время до последнего пикселя.
Запись UART запускается отдельно до начала измерений.
