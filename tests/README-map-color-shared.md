# Общий цвет областей карты

Три оставшихся потребителя используют usp_alert_region_colors::color_hex:
полноэкранный кэш, смена палитры обычной карты и резервная карта главного экрана.
Порядок областей, кэш, задержки, геометрия и данные Neptun остаются прежними.
Баллистика в обычной палитре остаётся фиолетовой, 0xA855F7.

map-color-shared-static.py проверяет три профиля без доступа к секретам.
map-color-shared-native.py извлекает исполняемые выражения из настоящих
потребителей и сравнивает с сохранёнными прежними таблицами.
Проверяются 2048 значений состояния и все 256 значений палитры.
Три повреждённых потребителя обязаны компилироваться, затем отвергаться
при выполнении под ASan/UBSan. Ошибка компиляции не считается обнаружением.

Запуск: python3 tests/map-color-shared-native.py
Результаты сохраняются в новом artifacts/map-color-native-<время>.
Для отдельной копии используйте --config, --header и --output.
Справка: --help. Проверки не обращаются к панели и не изменяют источники.
