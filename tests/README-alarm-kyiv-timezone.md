# Будильник и реальные переходы Europe/Kyiv

Обычная проверка, без доступа к панели:

```sh
/root/config/.qa-venv/bin/python tests/alarm-kyiv-timezone-native.py
```

Сохранение входов и две проверки обнаружения ошибок:

```sh
/root/config/.qa-venv/bin/python tests/alarm-kyiv-timezone-native.py \
  --mutation-probes --output artifacts/my-kyiv-test
```

Программа находит изменения смещения Europe/Kyiv в системной базе ZoneInfo
за 2023–2026 годы. В каждой записи сохраняются UTC, местное время и ожидаемое
срабатывание. Даты переходов не задаются вручную. Ожидание — первое реальное
мгновение в дне, когда местное время достигло времени будильника: весной
пропущенные 03:00/03:30/03:59 срабатывают в 04:00, осенью — только в первый час.

Настоящий Schedule из production заголовка исполняет восемь трасс по 161
минуте с ASan/UBSan. Проверяются три будильника, восстановление fired_day,
ограничение дней недели, отсутствие срабатывания при загрузке и скачке UTC.

Для мутаций меняются только копии заголовка в artifacts. Ошибки компиляции
не считаются обнаружением ошибки. Сохраняются версия tzdata, SHA256 зоны,
трассы и журналы. Системная база CT106 сейчас 2025b; результаты относятся
к этому снимку правил. Это не проверка будущего законодательства,
звука на панели, её часов или реального отключения питания.
