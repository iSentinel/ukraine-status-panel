Проверки raw8 + multipart8 выполняют исходный код обработчиков и настоящий парсер. Поля отказа, методы и начало requestAuthentication берутся из production при каждом запуске. Заменены только ввод тела и отправка HTTP-ответа. Подключение к устройству и запись flash не выполняются. Тестовый парсер 1.0.1 находится в vendor, лицензия сохранена без изменений. Запуск: python3 tests/web-auth-rejection-native.py; параметры: --help.
