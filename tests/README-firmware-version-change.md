# Проверка смены номера версии

Из корня проекта:

```sh
/root/config/.qa-venv/bin/python tests/firmware-version-change-native.py
```

Для сохранения копий и журналов укажите новый каталог:

```sh
/root/config/.qa-venv/bin/python tests/firmware-version-change-native.py \
  --output artifacts/my-version-check
```

Программа копирует Python-тесты и профили YAML, заменяет номер версии
только в копиях и запускает статические тесты, использующие общий помощник
версии. Производственные компоненты и справочные файлы подключены только
для чтения. Проверяются также намеренно фиксированный маркер и отсутствие
версии; эти контрольные ошибки должны быть отклонены.

Номер 0.115.999-dev используется только внутри проверки. Сборка, прошивка
панели и обращения к устройству не выполняются. Скрипт не является
инструментом выпуска и не меняет версию проекта.
