# Отмена ошибочного касания GT911

Драйвер поддерживает необязательный on_cancel. Без него политика ошибок не меняется. Панель явно подключает обработчик: он сбрасывает LVGL pointer и жест до release, чтобы ошибка не нажала кнопку. После ошибки удерживаемый палец игнорируется до корректного кадра без касаний. Не готовый/некорректный кадр не считается отпусканием.

Запуск: ESPHOME_BIN=/opt/esphome/.venv/bin/esphome /root/config/.qa-venv/bin/python3 tests/gt911-fault-native.py

Параметры: --help, --touchscreen-source PATH, --compiler NAME. Проверяются actual GT911 и установленный ESPHome touchscreen; I2C/таймеры заменены. Ошибки пяти операций,600 повторов, optional opt-in, удерживаемый палец, отпускание и восстановление. tests/lcd-navigation-lvgl-native.py отдельно собирает настоящий LVGL и проверяет отсутствие клика/переключения/меню/свайпа. Эти проверки не подают ошибки на физическую шину.
