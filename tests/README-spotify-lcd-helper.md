# Spotify: обновление экрана

YAML получает один снимок воспроизведения и вызывает помощник из
include/usp_spotify_lcd.h. Все обращения к LVGL остаются в основном потоке.
Фоновый обработчик передаёт только данные и безопасное состояние подключения.

Подписи и цвета находятся в playback_status.h; форматирование названия,
исполнителя, альбома или подкаста — в playback_captions.h.
Функции небольшие, без сетевых запросов и самостоятельных выделений памяти.
Строки из снимка используются только на время вызова обновления экрана.

Кнопки управления остаются отключёнными. Повторный вывод тех же значений
не меняет подписи и положение ползунков. После отключения прогресс,
громкость и прежние названия очищаются моделью представления.

Для проверки: python3 tests/spotify-lcd-helper-native.py --help.
Тесты используют настоящие файлы помощников, ASAN/UBSAN и подмену границы
LVGL. Дополнительно выполняется проверка настоящим компилятором ESP32.
Это не заменяет визуальную проверку физического дисплея.
Наличие валидной Unicode-строки не гарантирует наличие каждого глифа
в ограниченном наборе шрифтов панели.

Public first-flash использует самостоятельный отключённый экран без
ссылок на приватный обработчик Spotify.
