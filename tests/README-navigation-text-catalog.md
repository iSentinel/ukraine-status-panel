# Проверка подписей навигации

Запуск: python3 tests/navigation-text-catalog-native.py --help.
Опция --build-dir сохраняет результаты в новом каталоге.

Тест компилирует настоящий include/usp_navigation_text.h под ASAN/UBSAN.
Ожидаемые тексты UA/RU/EN сохранены в fixtures/navigation-text-catalog-golden.cpp:
они побайтно совпадают с прежним встроенным образцом.3840 сравнений
проверяют восемь страниц, оба режима, меню и выбор украинского для
недопустимого значения языка. Проверяются также потребители в shared YAML.

Физическая панель и её настройки не затрагиваются. Читаемость и геометрия
оцениваются отдельными проверками; этот тест подтверждает точность строк.
