# Проверка текста комнатного датчика

Запуск: python3 tests/indoor-entry-text-native.py; параметры: --help.
--build-dir сохраняет каждый результат в новом каталоге artifacts.

Тест извлекает действующие два обработчика из YAML и сравнивает их
с прежними телами: 36864 сочетания языка, обнаружения, готовности
и конечных/NaN/бесконечных значений. Проверяются обе пары виджетов,
цвета, округление, 1024 значения каталога и 512 недопустимых ключей.
10 отрицательных вариантов меняются только на копиях; каждый сначала
должен скомпилироваться. Физический датчик и панель не используются.
