# Значок Wi-Fi на панели

В верхней строке вместо «Wi-Fi / ЕСТЬ / НЕТ» показан векторный значок:
три зелёные дуги — сильный сигнал (от −60 dBm), две — средний
(от −70 dBm), одна жёлтая — слабый. Жёлтая точка с пустыми дугами
означает подключение без достоверного измерения. Перечёркнутый значок —
связи нет. Это состояние локального Wi-Fi, а не проверка интернета.

Значок обновляется после загрузки, при подключении/отключении и раз в
секунду. Повторное состояние не перерисовывается. Смена языка и листание
для обновления не нужны. Настройки подключения, сканирования и OTA не меняются.

Проверки: `python tests/wifi-icon-static.py --help`; затем
`python tests/wifi-icon-static.py`. Проверка настоящей LVGL входит в
`tests/lcd-navigation-lvgl-native.py` и полный regression: пять различных
отрисованных состояний, пороги, восстановление после отключения,
2000 повторов стабильного сигнала и отсутствие повторных callbacks.
Это программная проверка; видимость и состояние после реальной загрузки
отдельно проверяются на физической панели.
