# Проверка запуска переключателя звука будильника

Запуск: ESPHOME_BIN=/opt/esphome-2026.10.1/bin/esphome python3
tests/alarm-switch-boot-native.py --build-dir /tmp/usp-alarm-boot-result

Компилируются полные неизменённые switch.cpp и template_switch.cpp, а также
их заголовки из установленного ESPHome. Адрес пакета можно указать через
--framework-root. Штатные restore/control/setup/write_state/loop выполняются
в тесте; заменены только платформенные хранение, журнал, callbacks и Entity.

Проверяются значение ON при первом запуске, сохранённые ON и OFF,
отсутствие действий при загрузке, работа пользовательских ON/OFF,
1000 повторных запусков и отсутствие второго хранилища у переключателя.
ASAN/UBSAN проверяют этот программный сценарий. Физический звук и NVS
на устройстве требуют отдельной проверки; этот тест их не подтверждает.
