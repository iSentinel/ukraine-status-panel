# Подписи Настроек

Запуск: /root/config/.qa-venv/bin/python3 tests/settings-text-catalog-native.py

--help показывает справку. --build-dir НОВЫЙ_КАТАЛОГ сохраняет исходник
проверки, полный вывод компилятора и результат; старый каталог не заменяется.

Проверяются настоящий usp_settings_text.h, именованные ключи15 подписей,
три языка и резервный язык:3840 сравнений с проверками памяти.
Файл settings-text-consumers.json задаёт15 реальных виджетов; в их прежних
языковых ветвях должны остаться45 обновлений текста.
Задержки, цвета и подтверждение перезапуска проверяются сравнением
конфигурации текущего выпуска с предыдущим сохранённым исходником.
Проверка не подключается к панели и не выполняет сборку образа или OTA.
